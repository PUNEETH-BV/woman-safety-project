ℹ How It Works

BLE Mesh creates a peer-to-peer safety network with nearby SafeGuard users. When you trigger SOS, an encrypted packet hops through discovered mesh nodes, extending your alert reach even without internet connectivity. The network graph above visualizes discovered peers and relay paths in real-time.

⚠ Note: Full BLE mesh requires native app support. This uses Web Bluetooth for basic scanning with a simulation layer for the relay visualization.
